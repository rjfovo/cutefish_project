# Cutefish TextEditor 功能清单

> 最后更新：2026-08-11
> cutefish-texteditor（CutefishOS 文本编辑器）当前已实现功能的完整清单。
> 配套阅读《架构设计.md》《核心流程.md》。

---

## 1. 界面结构（Notepad++ 风格）

```
┌──────────────────────────────────────────────────────────┐
│ 菜单栏    File  Edit  Search  View                       │
│ 工具栏    [新建][打开][保存] | [撤销][重做] | [剪切][复制][粘贴] │
│ 标签栏    ┌────────┐ ┌────────┐                          │
│           │ a.txt* │ │ b.txt  │   （双击空白=新建）        │
│ 编辑区    ┌─────────────────────────────────────────────┐ │
│ 状态栏    │ 行号 | TextArea 编辑区                       │ │
│           └─────────────────────────────────────────────┘ │
│           行:列  字符数  语言  UTF-8  Zoom 100%           │
└──────────────────────────────────────────────────────────┘
```

---

## 2. 文件操作

| 功能 | 说明 | 触发方式 |
|---|---|---|
| 新建标签 | 分配"新建文本 N"编号 | `Ctrl+N` / 菜单 / 工具栏 / 双击标签栏空白 |
| 打开文件 | 已打开则切到该标签 | `Ctrl+O` / 菜单 / 工具栏 |
| 命令行打开 | 支持裸路径与 `-f` 参数，多文件 | `cutefish-texteditor a.txt b.txt` |
| 文件管理器关联 | `FileHelper.addPath()` 接收外部打开请求 | 桌面/文件管理器"打开方式" |
| 保存 | 有路径直接写 | `Ctrl+S` / 工具栏 / 菜单 |
| 另存为 | 弹保存对话框 | `Ctrl+Shift+S` / 菜单 |
| 拖放打开 | 文件拖入窗口打开标签 | 拖放 |

## 3. 多标签页

| 功能 | 说明 |
|---|---|
| 标签切换 | 单击标签切换当前文档 |
| 关闭标签 | 关闭按钮 / `Ctrl+W` / 右键菜单 |
| 关闭其他 | 右键 → Close Others（从后往前逐个关闭） |
| 关闭最后标签 | **直接退出程序**（不新建空标签） |
| 标签右键菜单 | Close / Close Others / Save / Save As |
| 标签标题 | 文件名 + 未保存 `*` |
| 标签图标 | 灰笔=已保存；红笔=未保存 |
| 选中态 | 蓝色背景 + 线框 |
| 关闭按钮 | 未选中标签也显示；悬停红圆+白叉 |
| 工具提示 | 悬停标签显示完整文件名 |

## 4. 编辑操作

| 功能 | 说明 |
|---|---|
| 撤销 / 重做 | 工具栏/菜单/`Ctrl+Z` `Ctrl+Y` |
| 剪切 / 复制 / 粘贴 | 工具栏/菜单/快捷键 |
| 全选 | 菜单/`Ctrl+A` |
| 插入 Tab | 编辑区 Tab 键插入制表符（不移动焦点） |

## 5. 查找 / 替换

| 功能 | 说明 |
|---|---|
| 查找 | `Ctrl+F`，输入即搜（防抖） |
| 替换 | `Ctrl+H`，显示替换行 |
| 下一个 / 上一个 | `F3` / `Shift+F3` |
| 区分大小写 | 勾选项 |
| 全词匹配 | 勾选项 |
| 替换当前 / 替换全部 | 替换行按钮 |
| 收起 | Esc / 关闭按钮 |

## 6. 显示 / 视图

| 功能 | 说明 |
|---|---|
| 行号 | 可开关（View 菜单） |
| 语法高亮 | KSyntaxHighlighting，按文件扩展名推断语言 |
| 高亮主题 | Breeze Light（亮色） / Breeze Dark（暗色），跟随 FishUI 主题 |
| 文本缩放 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` 重置；状态栏显示百分比 |
| 字体设置 | View → Font 子菜单，动态列出系统等宽字体（fonts.js 缓存） |
| 跳转到行 | `Ctrl+G` |
| 状态栏 | 行:列、字符数、语言、编码（UTF-8）、缩放比例 |

## 7. 未保存保护

| 场景 | 行为 |
|---|---|
| 关闭未保存标签 | 弹确认框：不保存 / 保存 / 取消（右上角×=取消） |
| 退出时有未保存标签 | 弹确认框：Discard All / Save All / Cancel |
| 保存全部 | 逐标签保存；无路径的新文件先弹另存为，完成后退出 |
| 强制退出 | Discard All 置 `_forceQuit` 绕过 onClosing 拦截 |

## 8. 外部文件监视

| 场景 | 行为 |
|---|---|
| 文件被外部修改 | 弹警报：Reload / Auto Reload / Ignore |
| 文件被删除 | 弹警报：Save（重新保存恢复） |

## 9. 快捷键一览

| 快捷键 | 功能 |
|---|---|
| `Ctrl+N` | 新建标签 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| `Ctrl+W` | 关闭标签 |
| `Ctrl+Q` | 退出 |
| `Ctrl+F` / `Ctrl+H` | 查找 / 替换 |
| `F3` / `Shift+F3` | 下一个 / 上一个 |
| `Ctrl+G` | 跳转到行 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 放大 / 缩小 / 重置缩放 |
