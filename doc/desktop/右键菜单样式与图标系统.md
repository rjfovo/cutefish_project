## 2. 统一右键菜单样式设计

### 2.1 设计原则

内容与渲染分离、**单一渲染器**：所有应用菜单统一使用 `FishUI.DesktopMenu`
（QML 弹出窗口）+ `FishUI.MenuItem` + `FishUI.MenuSeparator`。一处增强（fishui），
全系统（桌面、文件管理器、dock、其它 QQC2 菜单）受益。

### 2.2 菜单容器 `FishUI.DesktopMenu`

| 项 | 值 | 说明 |
|---|---|---|
| 圆角 | 10px | 非合成环境回退 0 |
| 背景 | `Theme.secondBackgroundColor`，合成时透明度 **0.85** | 原 0.6 过透、文字发虚 |
| 边框 | 1px（暗色 白 18% / 亮色 黑 12%） | |
| 阴影/模糊 | `WindowShadow` + `WindowBlur` | |
| 内容内边距 | 上/下/左/右 **6px** 对称 | 消除原底部多余空白 |
| 项间距 | 0 | |
| 窗口尺寸 | `recompute()`：**可见内容 + 12px** | C++ 不再额外 `+16px` |

`recompute()` 在每次弹出前遍历可见子项重算 implicitWidth/Height，
保证窗口尺寸与可见菜单项完全贴合（菜单项会随 `updateMenuState()` 动态增删）。
另提供 `contentSize()` 供调用方（如 dock）在弹出前获取菜单尺寸以做**贴紧定位**。

### 2.3 菜单项 `FishUI.MenuItem`

| 项 | 值 | 说明 |
|---|---|---|
| 行高 | 30px 固定 | |
| 宽度 | 文字自适应（TextMetrics），最小 160px + 左右内边距 | 原固定 200px 大片留白 |
| 内边距 | 左/右 8px | |
| hover 高亮 | 圆角 **7px 胶囊**，上下内缩 2px | 不贴边 |
| 文字 | 14px；亮色 `#313136` / 暗色 `#F2F3F5`；禁用灰 | |
| 图标 | 16px，位于文字前 | |
| 勾选 | 左侧主题色 ✓（亮 `#0176D3` / 暗 `#7FC2FF`） | |
| 子菜单箭头 | 右对齐 `›`，垂直居中 | 原箭头堆在左上角 |
| 等宽 | `Layout.fillWidth: true` | |

### 2.4 分隔线 `FishUI.MenuSeparator`（新增）

自包含组件（不依赖 QQC2 style 解析）：高 9px（上下各 4px 呼吸空间）、1px 细线、
水平内缩 12px、颜色为文字色 15%~18% 透明度。

### 2.5 弹出定位 `MenuPopupWindow`（C++）

- **窗口尺寸**：直接取 QML 内容容器 implicit 尺寸（`recompute()` 已含 12px 内边距），
  删除原 `+16px` —— 它导致菜单底部不对称空白（实测桌面菜单从 200×406 → 188×309）。
- **`show()`**：弹到鼠标光标处（保留给"无参 popup"场景）。
- **`showAt(x, y)`**：指定位置弹出。
  ⚠️ 方法名**不能用 `popup`/`popupAt`** —— DesktopMenu.qml 里同名 QML 函数会**遮蔽** C++ 槽，
  导致 `popupAt()` 内部调用 `control.popup(x, y)` 实际执行的是 QML 自身（弹到鼠标处/递归）。
- **`setParentMenu()`**：子菜单把 transient parent 设为父菜单窗口，贴近屏幕右缘时
  自动**翻转到父菜单左侧**，而不是被钳制到屏幕边缘遮挡父菜单。

## 3. 菜单图标渲染架构

### 3.1 图标来源（两条路径）

| 来源 | 写法 | 加载方式 | 颜色 |
|---|---|---|---|
| **系统主题图标** | `icon.source: "image://icontheme/folder-new"` | `image://icontheme` 图片提供者 → `QIcon::fromTheme(name)` → 从图标主题（`Crule` 亮色 / `Crule-dark` 暗色）加载 | **彩色**（主题设计师配色），随明暗主题自动切换 |
| **应用内自定义 SVG** | `icon.source: "qrc:/images/open.svg"` | 直接加载应用资源（qrc）里的 SVG | **单色线条**（`stroke="currentColor"`），需着色适配主题 |

`image://icontheme` 提供者：`fishui`（`src/iconthemeprovider.cpp`）与 `dock`
（`src/iconthemeimageprovider.cpp`）各自注册了同名提供者，实现相同：
路径直接 `QPixmap(id)`，否则 `QIcon::fromTheme(id)`，失败回退 `application-x-desktop`。

### 3.2 渲染流程（`FishUI.MenuItem` 内部）

```
icon.source ──► Image { width:16, height:16, sourceSize: Qt.size(16,16) }
                    │
                    ├─► 直接渲染（未设 icon.color）：彩色主题图标按原样显示
                    │
                    └─► ColorOverlay { color: icon.color }（设了 icon.color 时）
                         按图标的 alpha 形状整体染成指定颜色（单色线条图标用）
```

### 3.3 关键实现细节

**① `sourceSize` 必须显式设置（重大 Bug）**

`Image` 若不设 `sourceSize`，`QQuickImageProvider` 收到无效请求尺寸，会被 provider
钳成 **1×1**，返回的 1×1 半透明灰像素被拉伸成 16×16 —— 即"图标显示为实心灰块/空白"。
实测：`QIcon::fromTheme("document-open").pixmap(1,1)` 返回
`(0.235, 0.217, 0.217, 0.217)`，与菜单里实测灰块 `(193,188,187)` 完全吻合。

**② 着色按需（`icon.color`）**

`ColorOverlay` 仅在调用方显式设置 `icon.color`（`alpha > 0`）时启用：
- 不设 → 保留图标原色（彩色主题图标，如桌面菜单的 `folder-new`、`edit-paste`）；
- 设 → 染成指定颜色（dock 自定义单色图标设 `FishUI.Theme.textColor`，明暗自适应）。

⚠️ 教训：早期实现把**所有**图标无条件染成文字色，导致彩色主题图标被"黑化"，
需改为按需着色。

### 3.4 各菜单图标配置

| 菜单 | 图标来源 | 是否着色 |
|---|---|---|
| 桌面右键菜单（FileContextMenu） | 全部主题图标（folder-new / document-new / edit-paste / edit-select-all / preferences-wallpaper / video-display / view-restore / document-open / window-new / system-run / edit-cut / edit-copy / user-trash / edit-delete / edit-rename / utilities-terminal / view-hidden / document-properties） | 否（彩色） |
| 文件管理器右键菜单 | 与桌面共用 FileContextMenu | 否（彩色） |
| dock 应用菜单 | 打开/固定/取消固定/关闭 = 自定义 `qrc:/images/{open,pin,unpin,close}.svg`；应用名 = 应用自身图标 | 自定义图标是（`FishUI.Theme.textColor`）；应用图标否 |
| dock 回收站菜单 | 打开 = `open.svg`；清空回收站 = 主题 `user-trash` | 自定义是；主题否 |

## 4. 修复的问题清单（含根因）

| # | 问题现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 菜单底部多余空白、上下不对称 | C++ `popup()` 额外 `+16px` | 删除 `+16`，尺寸由 QML `recompute()` 精确给出 |
| 2 | 子菜单弹到鼠标位置而非父项右侧 | QML 函数 `popup()` 遮蔽 C++ 槽 `popup(x,y)`，实际执行 `show()` | C++ 改名 `showAt(x,y)` |
| 3 | 子菜单贴近右缘被钳到屏幕边缘、遮挡父菜单 | 子菜单未设 transient parent，翻转逻辑不生效 | 新增 `setParentMenu()` + `parentMenuRef` |
| 4 | 菜单图标显示为"实心灰块/空白" | `Image` 未设 `sourceSize` → provider 返回 1×1 pixmap 拉伸 | `sourceSize: Qt.size(16,16)` |
| 5 | 桌面菜单彩色图标被染黑 | `ColorOverlay` 无条件染成文字色 | 改为按需（`icon.color` 显式设置才着色） |
| 6 | 全系统 QQC2 控件回退 Basic"demo"样式 | 会话设 `QT_STYLE_OVERRIDE=cutefish`，QQuickStyle 解析优先用 styleOverride（来自 QT_STYLE_OVERRIDE）而非 `QT_QUICK_CONTROLS_STYLE` | 各 QML 应用 `main()` 显式 `QQuickStyle::setStyle("fish-style")`（桌面/文件管理器/dock 已加） |
| 7 | 桌面右键菜单无图标 | FileContextMenu 纯文字 | 增加 `image://icontheme` 主题图标 |
| 8 | dock 右键菜单弹出遮挡其它图标 | `contextMenu.show()` 弹鼠标处 | `contentSize() + contextMenuPosition() + popupAt()` 贴紧 dock 边缘弹出（底部 dock 下边缘贴 dock 上边缘，水平居中对齐图标） |
| 9 | 菜单项高亮贴边、固定 200px 宽 | MenuItem 无内边距/固定背景宽 | 重构：胶囊高亮 + 自适应宽度 |

### 4.1 关于 `QT_STYLE_OVERRIDE` 的详细说明（问题 6）

`core/session/application.cpp` 设置了 `QT_STYLE_OVERRIDE=cutefish`（本意是让 QWidget
应用使用 cutefish 控件样式）。但 Qt Quick Controls 的样式解析逻辑
（`qtdeclarative/src/quickcontrols/qquickstyle.cpp`）顺序是：

```cpp
if (style.isEmpty())  style = QGuiApplicationPrivate::styleOverride;   // ← QT_STYLE_OVERRIDE 优先！
if (style.isEmpty())  style = qgetenv("QT_QUICK_CONTROLS_STYLE");        // 其次才看这个
```

于是所有 QML 应用都去加载不存在的 `cutefish` QML 样式模块，回退到 **Basic**（"demo"样式）。
`FishUI` 模块的 `initializeEngine` 里调用 `QQuickStyle::setStyle()` **无效**——样式在
`import QtQuick.Controls` 时就已解析，FishUI 初始化时机太晚且触发告警。
正确做法是**各应用在 `main()` 创建 QApplication 后、加载 QML 前**显式调用：

```cpp
QQuickStyle::setStyle(QStringLiteral("fish-style"));
```

## 6. 构建与部署（测试服务器 192.168.118.132）

```bash
# 构建
cd cutefish/code/fishui/build && cmake --build . -j$(nproc)          # libFishUI.so
cd cutefish/code/dock/build && cmake --build . -j$(nproc)            # cutefish-dock
cd cutefish/code/desktop/build && cmake --build . -j$(nproc)         # cutefish-desktop
cd cutefish/code/filemanager/build && cmake --build . -j$(nproc)     # cutefish-filemanager

# 部署（服务端 /usr，旧文件保留 .rjbak 备份）
cp libFishUI.so               /usr/lib/x86_64-linux-gnu/qt6/qml/FishUI/
cp fishui/src/controls/*.qml  /usr/lib/x86_64-linux-gnu/qt6/qml/FishUI/
cp cutefish-dock              /usr/bin/
cp libcutefish-filemodel.so   /usr/lib/x86_64-linux-gnu/

# 重启（session 会自动重启桌面；dock 需手动拉起）
pkill cutefish-dock; pkill cutefish-desktop
sudo -u ruanjian env DISPLAY=:0 XAUTHORITY=$XAU ... nohup /usr/bin/cutefish-dock &
```

> 注意：会话的 `XAUTHORITY` 会变化（`/proc/<desktop-pid>/environ` 里取最新值）。

## 7. 遗留与后续建议

- 其它 QML 应用（launcher、settings、texteditor、terminal、statusbar 等）如要确保
  fish-style 主题生效，需在各自 `main()` 加 `QQuickStyle::setStyle("fish-style")`。
- 系统托盘（StatusNotifierItem / DBusMenu）受协议限制仍使用 C++ `QMenu`，其视觉由
  `qt-plugins/widgetstyle/basestyle.cpp` 对齐。
- dock 菜单的贴紧定位目前覆盖底部/左/右三种方向；若未来支持顶部 dock 需在
  `DockItem::contextMenuPosition()` 补充。
